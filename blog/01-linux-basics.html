Linux 基础命令速查手册

2026-07-20 · Linux · 石定睿

作为一名实施工程师，日常工作中需要频繁在 Linux 服务器上操作。本文整理了最常用的 Linux 命令，方便快速查阅。

一、文件与目录操作

命令说明示例
ls列出目录内容ls -la /var/log
cd切换目录cd /etc/nginx
pwd显示当前路径pwd
mkdir创建目录mkdir -p /data/backup
cp复制文件cp -r source/ dest/
mv移动/重命名mv old.txt new.txt
rm删除文件rm -rf /tmp/cache/*
cat查看文件内容cat /var/log/nginx/access.log
tail查看文件末尾tail -f /var/log/syslog
grep文本搜索grep "error" app.log
find查找文件find / -name "*.log"

二、系统管理

# 查看系统信息
uname -a                  # 内核版本
cat /etc/os-release       # 发行版信息
hostnamectl               # 主机名

# 资源监控
top                       # 实时进程（按 q 退出）
htop                      # 增强版 top（需安装）
df -h                     # 磁盘空间
free -h                   # 内存使用
uptime                    # 运行时间 + 负载

# 进程管理
ps aux | grep nginx       # 查找进程
kill -9 PID               # 强制杀死进程
systemctl status nginx    # 查看服务状态

三、用户与权限

# 用户管理
useradd -m username       # 创建用户
passwd username           # 设置密码
usermod -aG docker user   # 加入 docker 组

# 权限管理
chmod 755 script.sh       # rwxr-xr-x
chown user:group file     # 修改所有者
chmod +x script.sh        # 添加执行权限

四、网络诊断

# 连通性测试
ping -c 4 8.8.8.8         # ping 4 次
traceroute baidu.com      # 路由追踪

# 端口检查
netstat -tlnp             # 查看监听端口
ss -tlnp                  # 同上（更快）
telnet 192.168.1.1 3306   # 测试端口是否开放

# DNS 检查
nslookup baidu.com        # 域名解析
cat /etc/resolv.conf      # DNS 配置

五、压缩与解压

tar -czf backup.tar.gz /data   # 打包压缩
tar -xzf backup.tar.gz          # 解压
zip -r archive.zip folder/      # zip 压缩
unzip archive.zip               # zip 解压

六、实施工程师常用组合

# 一键部署脚本模板
#!/bin/bash
set -e  # 遇到错误立即退出

echo "=== 开始部署 ==="

# 1. 更新代码
cd /app && git pull origin main

# 2. 安装依赖
npm install --production

# 3. 重启服务
systemctl restart myapp

# 4. 检查状态
sleep 3
systemctl status myapp

echo "=== 部署完成 ==="
