Docker 容器化部署入门实战

2026-07-25 · Docker · 石定睿

什么是 Docker？

Docker 是一个容器化平台，可以把应用和依赖打包成一个"集装箱"，在任何 Linux 服务器上都能跑。对实施工程师来说，Docker 最大的好处是：环境一致性——开发环境什么样，部署环境就什么样，彻底解决"我这能跑你那儿不行"的问题。

核心概念

  • 镜像（Image）：容器的模板，只读。类似 ISO 系统安装盘。
  • 容器（Container）：镜像的运行实例。类似你用 ISO 装好的虚拟机。
  • Dockerfile：镜像的"配方"文件，定义怎么构建镜像。
  • docker-compose.yml：编排多个容器的配置文件。

安装 Docker

# Ubuntu 一键安装
curl -fsSL https://get.docker.com | bash

# 启动并设置开机自启
systemctl start docker
systemctl enable docker

# 验证安装
docker --version
docker run hello-world

常用命令

# 容器管理
docker ps                    # 运行中的容器
docker ps -a                 # 所有容器（含已停止）
docker start/stop/restart ID # 启停
docker logs -f ID            # 实时查看日志
docker exec -it ID bash      # 进入容器内部
docker rm ID                 # 删除容器

# 镜像管理
docker images                # 本地镜像列表
docker pull nginx:latest     # 拉取镜像
docker rmi ID                # 删除镜像
docker build -t myapp:v1 .   # 构建镜像

实战：用 Docker Compose 部署 Nginx + 应用

# docker-compose.yml
version: '3.8'
services:
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html
      - ./nginx.conf:/etc/nginx/nginx.conf
    restart: always

  app:
    build: .
    ports:
      - "8080:8080"
    depends_on:
      - mysql
    restart: always

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: StrongPass123!
      MYSQL_DATABASE: myapp
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
    restart: always

volumes:
  mysql_data:
# 启动所有服务
docker-compose up -d

# 查看运行状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 停止所有服务
docker-compose down
